工作台 / 数据源设置

SRC数据源授权与额度

产品自身不实现爬虫。数据获取一律走合规的第三方数据服务或官方 API；数据源不可用时显性报错，不用推测数据填补。

失败码与处理规则

返回码 / 情形UI 表现任务状态
secret_no_remaining额度耗尽 顶部横幅预警 + 引导充值，拦截新任务提交不创建
secret_expired凭据过期 引导前往数据源后台续期FAILED
secret_unauthorized未授权 引导重新授权FAILED
翻页条数与 total 不一致样本不完整 明示实际抓取条数与应有条数FAILED，不降级出报告
部分长尾词无搜索量（返回 null）正常 渲染为「—」而非 0不阻断
接口超时已停止 停止并保留请求记录，结果不明时不自动重试FAILED

凭据管理约束

  • MCP / API 凭据仅在服务器受限环境中使用，前端不可见，禁止出现在任何日志、报告、导出文件中。
  • 前端只允许持有计划批准的公开钥匙；服务端密钥不下发到浏览器。
  • 原始响应按任务留底；当前未启用自动删除。
  • ASIN 维度缓存 24 小时；命中缓存时报告页显著标注生成时间并提供「强制刷新」——不允许让用户误以为看到的是实时数据。
